# Miao Yu · Academic Homepage

A minimal, publication-first academic homepage for Miao Yu, focused on trustworthy AI,
LLM post-training, and autonomous agents. The layout draws on established academic-site
patterns: a compact profile, a chronological news section, and dense publication metadata.

The site is intentionally dependency-free and can be published directly with GitHub Pages.

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
